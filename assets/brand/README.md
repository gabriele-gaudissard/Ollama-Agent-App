# Veyq identity

The original **split-V** symbol combines a descending V with an ascending arm interrupted by one precise cut: intent, action and a deliberate permission boundary. Its simple silhouette remains readable in a 16-pixel Windows icon. The wordmark uses restrained spacing and the application's mint/charcoal palette.

Use `logo-dark.svg` / `logo-dark.png` on dark surfaces and `logo-light.svg` / `logo-light.png` on light surfaces. `mark-dark.svg` is the compact in-app symbol. `veyq-dark.ico` contains 16, 24, 32, 48, 64, 128 and 256-pixel sizes. Preserve proportions and the cut in the right arm.

Vector originals and PNG/ICO exports are included. To regenerate, install `resvg-py` and `Pillow`, then run `python scripts/build_brand.py`. These development tools are not required to run Veyq.
