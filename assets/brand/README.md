# Veynuq identity

The original **split-V** symbol combines a descending V with an ascending arm interrupted by one precise cut: intent, action and a deliberate permission boundary. Its simple silhouette remains readable in a 16-pixel Windows icon. The wordmark uses restrained spacing and the application's mint/charcoal palette.

Use `logo-dark.svg` / `logo-dark.png` on dark surfaces and `logo-light.svg` / `logo-light.png` on light surfaces. `mark-dark.svg` is the compact in-app symbol. `veynuq-dark.ico` contains 16, 24, 32, 48, 64, 128 and 256-pixel sizes. Preserve proportions and the cut in the right arm. The Veynuq wordmark retains the original split-V symbol, colors and deliberate boundary.

Vector originals and PNG/ICO exports are included and ready to use. Brand-generation tools are local maintenance files and are not required to run Veynuq.
